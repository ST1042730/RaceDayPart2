
# RaceDay API Features

## 1. User Authentication
Users can register and log in securely using JWT authentication.

## 2. User Profiles
Authenticated users can view and update their profile information.

## 3. Event Management
Organisers can create, view, update and delete events.

Supported event types:
- Running
- Walking
- Cycling

## 4. Event Categories
Organisers can create categories and assign them to events.

Event categories can include entry fees and participant limits.

## 5. Participant Enrolment
Participants can enrol in event categories and view their existing enrolments.

The API prevents duplicate enrolments.

## 6. Race Results
Organisers can record participant race results.

Participants can view their own results.

## 7. API Documentation
Swagger provides an interface for exploring and testing API endpoints.

## 8. Automated Testing
The project includes xUnit tests and GitHub Actions continuous integration.

## 9. Database Management
Entity Framework Core manages database access and schema migrations.
